# Matrix

Консольное приложение «Матрица» на C++, разработанное в рамках лабораторных работ по ООП.

## Описание

Программа отображает движущиеся снизу вверх зигзагообразные линии из случайных символов. Пользователь задаёт скорость, длину и режим отображения цветов.

- **Лабораторная №1:** последовательно создаётся по одной линии.
- **Лабораторная №2:** добавлена частота появления (1–30 линий/с), случайные моменты генерации и одновременное движение нескольких линий без дополнительных потоков. При появлении учитываются свободные позиции, а пересечения символов обрабатываются корректно.

Поддерживаются ввод параметров через командную строку, диалоговый режим и проверка значений.

## Технологии

- C++20

## Основные классы

- `Character` — символ и его цвет
- `Line` — положение, форма и движение линии
- `ApplicationManager` — создание линий, расписание и отрисовка
- `Console` — работа с консолью через WinAPI

## Сборка и запуск

Для сборки необходимы Windows и Visual Studio с компонентом «Разработка классических приложений на C++».

Откройте `Matrix.slnx`, выберите `Debug | x64` и нажмите `Ctrl + Shift + B`.

Запуск из PowerShell в корне проекта:

```
.\x64\Debug\Matrix.exe 3 23 8 Y
```

Для `lab-02` параметры указываются в порядке: **частота (1–30), скорость (1–30), длина (1–30), режим цвета (Y/N)**. В `lab-01` параметра частоты нет — передаются только последние три аргумента.

При запуске без аргументов используется диалоговый ввод. Для просмотра справки: `--help` или `/?`.
