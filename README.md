Matrix



Консольное приложение «Матрица», разработанное в рамках лабораторных работ по объектно-ориентированному программированию.



Описание:



Программа отображает движущиеся линии символов в консоли. Пользователь задаёт скорость линий, их длину и режим эпилепсии. Поддерживаются диалоговый и командный режимы ввода.



Проект последовательно развивается в рамках лабораторных работ.





Стек технологий:

* C++
* WinAPI





Ветки:

* develop — основная ветка разработки
* about — общее описание проекта и документация
* lab-01 — базовая реализация классов



Ветки lab-xx используются для финальных проверенных версий соответствующих лабораторных работ.





Сборка и запуск:

* Зависимости:

&#x09;Windows

&#x09;Visual Studio с компонентом «Разработка классических приложений на C++»





Сборка:

Откройте файл Matrix.slnx в Visual Studio и выполните сборку проекта сочетанием клавиш Ctrl+Shift+B.





Запуск:

Для запуска без отладки нажмите Ctrl+F5.

При запуске без параметров используется диалоговый режим.



Для запуска в командном режиме можно передать параметры через свойства запуска программы, например:

Matrix.exe 23 8 Y



Для вывода справки:

Matrix.exe --help

Matrix.exe /?
