# Matrix

Консольное приложение «Матрица» на C++, разработанное в рамках лабораторных работ по ООП.

## Описание

Программа отображает движущиеся снизу вверх зигзагообразные линии из случайных символов. Пользователь задаёт частоту появления, скорость, длину, режим отображения цветов и параметры взрывов.

- **Лабораторная №1:** последовательно создаётся по одной линии.
- **Лабораторная №2:** добавлена частота появления (1–30 линий/с), случайные моменты генерации и одновременное движение нескольких линий без дополнительных потоков. При появлении учитываются свободные позиции, а пересечения символов обрабатываются корректно.
- **Лабораторная №3:** добавлены вероятностные взрывы линий с настраиваемыми минимальным и максимальным радиусами. Взрыв представляет собой расширяющуюся волну из случайных разноцветных символов, движущуюся со скоростью 2 символа/с независимо от скорости линий. При каждом взрыве головной символ линии уничтожается, а её максимальная длина уменьшается на единицу.

Поддерживаются ввод параметров через командную строку, диалоговый режим и проверка значений.

## Основные классы

- `Character` — символ и его цвет
- `Figure` — абстрактный базовый класс с общим интерфейсом отрисовки фигур
- `Line` — положение, форма, движение линии и обработка вероятностных взрывов
- `Explosion` — генерация и анимация расширяющейся взрывной волны
- `ApplicationSettings` — структура для хранения параметров приложения
- `ApplicationManager` — создание линий и взрывов, расписание, обновление объектов и отрисовка
- `Console` — работа с консолью через WinAPI

## Сборка и запуск

Для сборки необходимы Windows и Visual Studio с компонентом «Разработка классических приложений на C++».

Откройте `Matrix.slnx`, выберите `Debug | x64` и нажмите `Ctrl + Shift + B`.

Запуск из PowerShell в корне проекта для `lab-03` и текущей версии `develop`:

```
.\x64\Debug\Matrix.exe 3 23 8 Y 250 2 5
```

Параметры указываются в следующем порядке:

1. **Частота появления линий** — 1–30 линий/с.
2. **Скорость движения** — 1–30 символов/с.
3. **Длина линии** — 1–30 символов.
4. **Режим эпилепсии** — `Y` (случайные цвета) или `N` (зелёный цвет).
5. **Вероятность взрыва** — 1–1000 (в тысячных долях на один шаг линии).
6. **Минимальный радиус взрыва** — 1–10.
7. **Максимальный радиус взрыва** — 1–10, но не меньше минимального.

При запуске без аргументов используется диалоговый ввод. Для просмотра справки: `--help` или `/?`.
